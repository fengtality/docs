New to Condor, or picking up where you left off? Use the tables below to find the fastest route to what you actually want to do—no need to read every page in order.

## By experience level

| Level | Goal | Reading path | Time |
|-------|------|--------------|------|
| **Beginner** | Get Condor and Hummingbot API running locally, send your first Telegram command, and build one Trading Agent | [Installing](/getting-started/installing) → [Telegram](/getting-started/telegram) → [Credentials](/getting-started/credentials) → [First Agent](/getting-started/first-agent) | ~30–45 min |
| **Intermediate** | Add real exchange keys, use the web dashboard, understand Bots/Executors/Routines, and manage running sessions | [Web Dashboard](/getting-started/web-dashboard) → [Bots](/bots/overview) → [Executors](/executors/overview) → [Routines](/routines/overview) → [Sessions](/getting-started/sessions) | ~1–2 hrs |
| **Advanced** | Deploy remotely with Tailscale, understand the multi-agent architecture, and build custom agents | [Installing (remote/Tailscale)](/getting-started/installing#secure-remote-access-with-tailscale) → [Trading Agents Architecture](/trading-agents/architecture) → [Agent Builder](/trading-agents/agent-builder) → [Managing Servers](/other-features/server) | ~2–4 hrs |

## What do you want Condor to do?

Condor gives you four ways to execute a trade, from fully autonomous to fully manual. Most users end up combining more than one.

| | Trading Agent | Bot | Executor | Routine |
|---|---|---|---|---|
| **Decision maker** | LLM, reasons every tick | Script/Controller, fixed logic | You, or an Agent (one-shot) | Deterministic Python |
| **Lifecycle** | Long-running, adaptive | Long-running, fixed | Short-lived, single operation | Scheduled or triggered |
| **Best for** | AI-assisted strategy that adapts to conditions | Always-on market making or grid trading without AI in the loop | A single trade, or a stop-loss/take-profit | Reports, alerts, and indicators without LLM cost |
| **Learn more** | [Trading Agents](/trading-agents/overview) | [Bots](/bots/overview) | [Executors](/executors/overview) | [Routines](/routines/overview) |

## Do I need Tailscale?

| Situation | Tailscale needed? |
|-----------|--------------------|
| Testing locally—Condor and Hummingbot API on one machine | No |
| Same VPS, both services together | Optional, still recommended |
| Different machines (for example, laptop + VPS) | **Yes** |
| A team or multiple devices need access | **Yes** |

See [Installing](/getting-started/installing#secure-remote-access-with-tailscale) for the full setup, or the [Tailscale security walkthrough](https://hummingbot.org/blog/posts/securing-condor-and-hummingbot-api-with-tailscale/) for a deeper guide.
