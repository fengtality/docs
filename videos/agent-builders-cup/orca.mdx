Build an AI trading agent that runs on **Orca**, a leading Solana DEX. Under the hood, the session shows how Condor uses GeckoTerminal (by CoinGecko) to pull its DEX data, then walks through adding a Solana wallet and creating an agentic strategy on Orca.

Part of the **[Agent Builders Cup](/videos/overview#agent-builders-cup)** — a one-month online hackathon where builders compete for a share of the **$20K prize pool** by deploying agents that trade real capital on live markets. Start with the [Hackathon Kickoff](/videos/ep13) session if you haven't seen it.
